# User guide
## App install
1. Put the app-release.apk in a folder on target phone
2. Allow permission to install unknown apps
3. Install without scanning (scanning sends the data to play store)
4. Open the app

## Before flight
1. Pick waypoint
2. Choose fineness ratio 
3. Choose wander radius
4. Wait for tiles to download
5. Get within wander range (the take off site)
5. Set altitude on ground at take off
6. Press launch and wait for first run of the algorithm to conclude
7. Fly.

## Running code (preferably on phone)
`flutter run`

## Testing code
All tests must pass!

`flutter test` to test all unit tests in /test/ folder.

`flutter test /test/...` to test a single unit test.

`flutter analyze` to get information about potential issues project wide.
