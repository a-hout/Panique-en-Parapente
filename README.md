# Panique En Parapente

## Running code
`flutter run`

## Running on an emulator of an android device
`flutter emulators --launch Medium_Phone_API_36.1`
`flutter run`

Allows to spoof location which is very useful in our case!

## Testing code
All tests must pass!

`flutter test` to test all unit tests in /test/ folder.

`flutter test /test/...` to test a single unit test.

`flutter analyze` to get information about potential issues project wide.
